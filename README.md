# Harshit Malhi - AI & ML Developer Portfolio

Welcome to the repository for Harshit Malhi's personal portfolio website, featuring engineering projects, internships, research papers, certifications, and technical competencies.

🌐 **Live Website:** [https://harshitmalhi30-boop.github.io/Harshit-Portfolio/](https://harshitmalhi30-boop.github.io/Harshit-Portfolio/)

---

## 🚀 Overview

This portfolio is an interactive, responsive web application showcasing:
- **Profile & Education:** Academic background, contact details, and career objectives in AI/ML & Embedded Systems.
- **Projects:**
  - **Micro-Sleep Detection System:** Arduino-based multi-parametric driver safety system utilizing LoRa communication, MPU-6050, IR sensors, and haptic feedback.
  - **Rapidox AI:** Artificial intelligence project focusing on rapid model integration and automated task solutions.
  - **Stock Tracker:** Python application using dictionaries, file handling, and loops to track stock portfolios.
  - **Hangman Game & Chatbots:** Interactive software built with clean Python logic.
- **Internships & Credentials:** Industry internships, credentials, and verification documents.
- **Research Papers & Certifications:** Academic publications and verified certifications.
